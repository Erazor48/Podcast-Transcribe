## podcast-transcribe

This app is made to be useful for podcasters who want to transcrybe an audio and can modify the output text.
The audio, visual sound track and the generated text using whisper are all corelated and help to generate the output and adapt this himself esay as possible.

The project begin whith the base of "https://asharibali.medium.com/building-an-audio-player-app-with-next-js-80d06cc1d7d8".
The I used shadecn for ui components (button, card, progress), next.js for the core app.
